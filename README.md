# La Mazmorra del Tiempo

Videojuego de plataformas 2D al estilo Prince of Persia, hecho con JavaScript y HTML5 Canvas.

## Cómo jugar
Abrir `index.html` con Live Server en VS Code.

## Controles
(Se completará con el movimiento del jugador)

## Estructura
- `js/player.js`: jugador
- `js/levels/`: un archivo por nivel
- `js/ui.js`: menú, HUD y pantallas
- `js/main.js`: bucle principal
